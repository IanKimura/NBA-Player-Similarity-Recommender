# Upload this cleanup

Repository: https://github.com/IanKimura/NBA-Player-Similarity-Recommender

1. Extract `nba-player-similarity-github-ready.zip`.
2. Open the extracted folder in Finder.
3. In GitHub, choose Add file → Upload files.
4. Drag the contents of the extracted folder, including closed subfolders, into
   the upload box. `README.md` and `requirements.txt` belong at the root.
5. Confirm paths include `figures/player_map.png` and `app/app.py`.
6. Commit with `Clean up NBA recommender and add visual documentation`.

GitHub will replace the existing root README when you commit the upload. Uploading
does not remove old placeholder files. `app/READM.md`, `notebooks/README.md`, and
`src/README.md` can remain harmlessly or be removed later through GitHub's UI.
The package replaces `data/README.md` with useful provenance information.
